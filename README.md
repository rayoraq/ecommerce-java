# E-commerce (Java): Product & ShoppingCart

![CI](https://github.com/rayoraq/ecommerce-java/actions/workflows/ci.yml/badge.svg)

Лабораторная работа №3: модульные тесты, CI, GitHub Actions.

## Назначение проекта
- `Product` - карточка товара из каталога, содержащая неизменяемые данные и проверку характеристик
- `ShoppingCart` - корзина покупателя с учетом остатков на складе, применением промокодов и расчетом итоговой стоимости со скидкой
- `PromoCode` - допустимые промокоды и размер скидки

## Стек технологий

* **Java 17**
* **Maven** (сборка и управление зависимостями)
* **Project Lombok** (сокращение шаблонного кода)
* **JUnit 5** (модульное тестирование)
* **JaCoCo** (проверка покрытия кода)

## Запуск локально

Сборка проекта, запуск тестов и проверка покрытия (порог 80%):

    mvn clean verify
