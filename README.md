# E-commerce (Java): Product & ShoppingCart

![CI](https://github.com/rayoraq/ecommerce-java/actions/workflows/ci.yml/badge.svg)

Лабораторная работа №3: модульные тесты, CI, GitHub Actions.

## Функциональное назначение

Проект представляет собой часть бизнес-логики корзины интернет-магазина.

### Решаемые задачи:

* **Учет остатков:** контроль доступного количества товаров при добавлении в корзину;
* **Управление заказом:** добавление и удаление позиций;
* **Система скидок:** валидация промокодов и пересчет итоговой суммы;
* **Контроль качества:** автоматическая проверка с помощью JUnit 5 и AssertJ, контроль покрытия кода от 80% через
  JaCoCo.

### Состав проекта

- `Product` - карточка товара из каталога, содержащая неизменяемые данные и проверку характеристик
- `ShoppingCart` - корзина покупателя с учетом остатков на складе, применением промокодов и расчетом итоговой стоимости
  со скидкой
- `PromoCode` - допустимые промокоды и размер скидки

## Стек технологий

* **Java 17**
* **Maven** (сборка и управление зависимостями)
* **Lombok** (сокращение шаблонного кода)
* **Apache Commons Lang 3** (`StringUtils`)
* **JUnit 5** (модульное тестирование)
* **AssertJ** (проверки в тестах)
* **JaCoCo** (проверка покрытия кода)

## Запуск локально

Сборка проекта, запуск тестов и проверка покрытия (порог 80%):

    mvn clean verify
