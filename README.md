# E-commerce (Java): Product & ShoppingCart

![CI](https://github.com/rayoraq/ecommerce-java/actions/workflows/ci.yml/badge.svg)

Лабораторная работа №3: модульные тесты, CI, GitHub Actions.

## Стек технологий
* **Java 17**
* **Maven** (сборка и управление зависимостями)
* **JUnit 5** (модульное тестирование)
* **JaCoCo** (проверка покрытия кода)

## Запуск локально
Сборка проекта, запуск тестов и проверка покрытия (порог 80%):

    mvn clean verify
